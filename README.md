# Used-Vehicle-estimation
# 🚗 Used Vehicle Price Estimation System

An AI/ML-based system that predicts the estimated resale price of **used cars and bikes** using vehicle details such as brand, model, year, kilometers driven, fuel type, transmission, owner, city, and body type.

## 🎯 Project Objective

The main objective of this project is to help users estimate the resale value of a used vehicle using Machine Learning.

The system supports:

- 🚗 Cars
- 🏍️ Bikes
